子代理配置

定义主 Agent 可以委派的对象；工具和专项提示词不会在这里写死。

01
身份与委派边界名称用于识别，用途说明决定主 Agent 何时选择它。
02
运行模型默认跟随主对话；固定模型适合稳定复现或成本隔离。
工具由主 Agent 本次授予只能从当前安全工具目录中选择；子代理不能递归委派，也不能直接读写长期记忆。
03
路由名片决定「什么时候派给它」。关键词或类别都为空时，它不参与自动路由（只作为兜底型子代理）。
04
可用状态停用后不会出现在主 Agent 的委派目录中。
