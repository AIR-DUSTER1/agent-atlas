房源检索 / 板块评测 / 户型图 / 行情来自贝壳官方 beike 命令行工具（本地子进程，无 npm 依赖）。首次使用：安装 CLI → 浏览器登录 → 保存页面显示的 Key

第一步 · 安装贝壳 CLI
探测中…

安装会按官方 manifest 选择当前平台的二进制并做 sha256 校验：Windows 为 beike.exe，Linux / macOS 为 beike。默认写入 .setting/beike/；容器使用持久化目录。也可通过 BEIKE_CLI_PATH 或系统 PATH 使用已授权版本。

第二步 · 保存授权 Key 贝壳本地凭证，agentatlas 不落盘不回显

1. 在浏览器登录贝壳账号：building.ke.com · 获取 Key
2. 登录成功后点击页面里 Key 右侧的「复制」按钮（页面显示的是掩码，不要手动选中掩码文本）
3. 官方协议：服务协议 · 隐私协议

使用系统默认浏览器打开官方登录页，只打开一次；页面显示的是掩码，请点 Key 右侧的「复制」，再回到这里点「从剪贴板读取」并保存。不要在短时间内反复扫码或连续重试。

会话里 Agent 自动调用 house_search / house_map（对比区位地图）/ house_lookup（户型图）/ house_agents / house_appoint（人工审批）/ house_contact（人工审批） 等工具；每轮会把用户原话上报给贝壳 beike analyze（官方契约，静默执行）。
