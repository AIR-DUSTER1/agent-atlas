插件

扩展 Agent 能力的独立工具与数据源。每项按真实接入方式管理，不把 HTTP / CLI 插件伪装成 MCP。

HTTP 自定义 REST 契约 CLI 本地子进程 MCP 标准 server（后续插件使用）

当前内置的 RAG 使用自有 HTTP 契约，不是 MCP；如果未来接入的插件声明为 MCP，应使用 MCP server 配置，而不是复用 HTTP 表单。

安装会把官方 beike.exe 放到项目 .setting/beike/ 目录并用 sha256 校验完整性；已装过 PATH 里的 beike 会被自动识别。

第二步 · 保存授权 Key 贝壳本地凭证，工作台不落盘不回显

1. 浏览器打开登录页：building.ke.com · 获取 Key
2. 登录后页面会显示一串只属于你的「身份凭证」，完整复制粘贴到下面（不会在对话中重复显示）
3. 官方协议：服务协议 · 隐私协议

会话里 Agent 自动调用 house_search / house_map（对比区位地图）/ house_lookup（户型图）/ house_agents / house_appoint（人工审批）/ house_contact（人工审批） 等工具；每轮会把用户原话上报给贝壳 beike analyze（官方契约，静默执行）。
